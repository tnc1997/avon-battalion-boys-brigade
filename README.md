# Avon Battalion Boys' Brigade

This project has been superseded. The Avon Battalion Boys' Brigade digital presence is
being replaced by a new website built on **WordPress**, hosted on the Boys' Brigade
shared hosting platform.

As a result, this Flutter application is being retired. This repository is being kept
in its current, read-only state purely to **preserve the project's history** — including
its commits, issues, and pull requests — for future reference. It should **not** be used
as the basis for any new work, and no further changes, features, or fixes will be made
here.

If you are looking for the current, live website, please refer to the new WordPress site
rather than this repository or any build produced from it.

## Why this change happened

The move to WordPress on the Boys' Brigade shared hosting platform was made so that the
site can be:

- Maintained more easily by non-technical volunteers, without requiring Flutter/Dart
  development knowledge or a build/release pipeline.
- Hosted consistently alongside other Boys' Brigade digital properties on shared
  infrastructure that is already managed and supported centrally.
- Kept up to date with content changes (news, events, contact details, etc.) without
  needing a developer to make and deploy code changes.

## About this project

This repository contained a [Flutter](https://flutter.dev/) application for the Avon
Battalion of the Boys' Brigade. It was originally generated as a starting point for a
Flutter application and was subsequently developed into a small informational app/site
for the battalion (including sections such as finding a local company/section and other
battalion information).

## What happens to this repository

- The repository will remain in an **archived** state so that its commit
  history, discussions, issues, and pull requests remain accessible.
- No new commits, branches, releases, or issues should be opened against this
  repository going forward.
- Any dependencies, secrets, or deployment configuration associated with this project
  should be considered decommissioned alongside the application itself.

## Questions

For questions about the new website or about the decision to retire this application,
please contact the Avon Battalion Boys' Brigade leadership or the individual who
maintained this repository.
